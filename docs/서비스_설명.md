# 서비스 설명

이 문서는 **코드가 어떻게 짜여 있는지** 훑어보려는 분을 위한 안내입니다.
서비스 소개와 실행 방법은 맨 위 폴더의 `README.md` 에 있습니다.

---

## 1. 한 번 의뢰하면 벌어지는 일

사용자가 상담소에서 **지역·업종·관측 기간**을 고르고 "이 조건으로 의뢰하기"를 누르면 이렇게 진행됩니다.

```
1. 뉴스 수집       네이버 뉴스에서 그 지역 기사를 모아
                   '뉴스 수집 컴퓨터'에 저장하고 검색용 색인을 만든다  (코드)

2. 화제 탐지       김쫑긋 사원이 기사를 읽고
                   화제가 된 동네·업종 후보 10~15개를 고른다           (모델)

3. 테마 연결       박이음 대리가 후보를 상권 테마로 묶는다
                   (재개발 / 축제 / 임대료·공실 …)                     (모델)

4. 상권 분석       오꼼꼼 과장이 동네마다 공공 상가 데이터를 조회해
                   업종 구성을 세고 등급 A~D를 매긴다        (코드 계산 + 모델 해설)

5. 리포트 작성     정또박 팀장이 소상공인이 읽을 리포트를 쓴다          (모델)

6. 보고서 조립     코드가 결과를 모아 대시보드로 만든다                (코드)
```

각 단계가 끝날 때마다 **결과 형식을 검사**하고, 통과한 것만 다음 단계로 넘어갑니다.
중간에 멈추면 사무실 화면에 어느 부서에서 멈췄는지 표시됩니다.

## 2. 숫자는 코드가, 글은 모델이

보고서에 나오는 숫자는 모델이 만들지 않습니다.

| 항목 | 누가 만드나 | 근거 |
|---|---|---|
| 점포 수 | 코드 | 소상공인시장진흥공단 상가(상권)정보 |
| 업종 구성비 | 코드 | 위 데이터를 세어서 계산 |
| 업종 집중도 | 코드 | 상위 업종 비중으로 계산 |
| 상권 등급 A~D | 코드 | 정해 둔 기준표에 대입 |
| 화제 동네 선정 | 모델 | 기사 본문을 읽고 판단 |
| 상권 테마 | 모델 | 기사 맥락으로 묶음 |
| 소상공인 조언 | 모델 | 위 숫자와 기사를 근거로 작성 |

그래서 **같은 지역을 다시 돌려도 숫자는 같고**, 모델을 바꿔도 숫자는 달라지지 않습니다.

## 3. 직원이 자료를 찾는 두 가지 방법

### 자료 검색 (RAG)

수집한 기사와 전문 자료를 잘게 쪼개 **의미를 담은 벡터**로 바꿔 두고, 질문과 가까운 조각을 찾아옵니다.

- 임베딩 모델: `BAAI/bge-m3`
- 벡터 저장: LanceDB (`data/agents/<직원>/index/`, `data/libraries/<컴퓨터>/index/`)
- 찾은 뒤 리랭커로 한 번 더 추립니다

계산은 **이 PC** 로 하거나, 따로 둔 **GPU 장비**로 넘겨서 할 수 있습니다. **기본은 이 PC** 이고(`.env` 에 장비 주소를 적어도 보관만 합니다), 사무실 → 뉴스 수집 컴퓨터 화면에서 버튼 하나로 바꾸고, 장비 주소도 그 화면에서 지정합니다. 기사를 많이 모을수록 GPU 쪽이 빠릅니다.

### 지식 그래프

행정구역, 상권 테마, 등급 기준처럼 **관계가 중요한 지식**은 그래프로 담았습니다.
예를 들어 "중앙동"이 어느 구에 속하는지, 어떤 테마가 어떤 업종과 이어지는지를 따라갈 수 있습니다.

직원 소개 화면의 "지식 그래프" 탭에서 각 직원이 가진 그래프를 볼 수 있습니다.

## 4. 폴더 구조

```
app/                서버 (Python · FastAPI)
  agents/             직원 정보 읽고 쓰기
  chat/               모델 호출 (DeepSeek · Claude · OpenAI · Gemini)
  libraries/          뉴스 수집 컴퓨터 (기사 수집·보관)
  offices/            회사 흐름 실행, 대시보드 만들기
  rag/                자료 검색 (임베딩·색인·검색·지식 그래프)
  runs/               업무 실행 기록, 결과 검증
  tools/              직원이 쓰는 도구들
  regions.py          지역 정보 (시·군·구·동)

static/             화면 (HTML · CSS · JavaScript, 빌드 없이 그대로 동작)
  app.js              화면 전환, 상담소, 열람실, 직원 대화
  offices.js          사무실 화면 (직원·컴퓨터·말풍선)
  libraries.js        뉴스 수집 컴퓨터 화면
  graph_tab.js        지식 그래프 보기
  theme_v3.css        지금 쓰는 디자인

data/               데이터 (이 폴더만 지우면 초기 상태가 됩니다)
  agents/             직원 4명 (성격·업무·도구·전문자료·지식그래프)
  libraries/          뉴스 수집 컴퓨터 5대 (기사 원문과 색인)
  offices/            회사 구성과 실행 기록
  config/             지역 정보, 색인 장비 설정
```

## 6. 직원 성격을 바꾸려면

각 직원의 지시문은 `data/agents/<직원 id>/persona.md` 에 글로 적혀 있습니다.
사람이 읽을 수 있는 문장이고, 고치면 다음 실행부터 반영됩니다.

| 직원 | 폴더 |
|---|---|
| 김쫑긋 사원 (화제 탐지) | `data/agents/a_7612ec55/` |
| 박이음 대리 (테마 연결) | `data/agents/a_bcb2ef08/` |
| 오꼼꼼 과장 (상권 분석) | `data/agents/a_a28223e1/` |
| 정또박 팀장 (편집장) | `data/agents/a_b5f24ab2/` |

같은 폴더의 `docs/` 에 그 직원이 참고하는 전문 자료가, `hooks/` 에 결과를 검사하는 코드가 있습니다.
