# 상권 화제 판별 가이드 (화제 탐지 담당자용)

> 초안 2026-09-29 · 대표님 검토 전. 경남 시·군(창원·진주·김해·양산·거제)을 의뢰받아 진단한다. 아래 예시는 창원 기준이다.

## 1. 무엇을 찾나
"이번 주 의뢰 지역의 어느 동네·업종이 화제였는가"를 뉴스에서 찾는다. 종목처럼 정확한 코드가 없으니, 화제 점수 도구(`changwon_buzz`)가 준 순위를 출발점으로 하되 **기사를 실제로 읽고 확인**한다.

## 2. 화제로 인정하는 사건 유형
| 유형 | 예시 | 화제 세기 |
|---|---|---|
| 신규 대형시설 개장 | 대형마트·복합몰·터미널 리모델링 | 강함, 오래 감 |
| 축제·행사 | 진해 벚꽃 축제·마산 딸기 축제(창원), 남강유등축제(진주), 가야문화축제(김해) 등 | 강하지만 짧음(행사 기간) |
| 재개발·정비사업 | 원도심 재개발 착공·완료 | 강함, 상권 성격 자체가 바뀜 |
| 대중교통 변화 | 신설 역·버스 노선 개편 | 중간, 몇 달 뒤 상권에 반영 |
| 임대료·공실 이슈 | "공실률 급증", "임대료 하락" | 경고 신호(화제이지만 부정적) |
| 특정 업종 몰림 | "OO동에 카페 우후죽순" | 과열 신호일 수 있음 — 상권 분석 담당자에게 넘겨 실제 점포 수 확인 |
| 안전·민원 이슈 | 주차난, 소음 민원, 치안 문제 | 소상공인에게 실질적 영향(부정적) |

## 3. 판별 함정
- **관공서 보도자료성 기사**(예: "OO동 도시재생사업 착수식")는 사실이지만 아직 상권에 영향이 없을 수 있다 — 착공인지 완공인지 구분.
- **한 해 반복되는 축제 기사**는 매년 비슷한 문구로 나온다. 올해 특별히 규모가 커졌는지·작아졌는지를 본다(작년 대비 언급이 늘었나).
- **동명이인·동명 지역**: "중앙동"처럼 여러 구·시에 같은 이름이 있다(예: 창원 의창구·진해구). 기사 맥락(다른 지명·시설 이름)으로 의뢰 지역의 어느 동네인지 확인한다.

## 4. 소상공인 관점에서 본 "좋은 화제" vs "나쁜 화제"
- 좋은 화제: 유동인구 증가 요인(신규 교통망, 관광객 증가, 신규 대형시설로 인한 낙수효과)
- 나쁜 화제: 임대료 급등, 공실 증가, 특정 업종 과포화(경쟁 심화), 안전 문제로 인한 기피

## 5. 넘길 후보 수
- 편집장이 5~8개 동네를 고르므로 10~15개 안팎을 넘긴다.
