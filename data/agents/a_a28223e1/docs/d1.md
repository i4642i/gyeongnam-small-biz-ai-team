# 상권 진단 기준서 (상권 분석 담당자용)

> 초안 2026-09-29 · **대표님 검토 필요**(어떤 상권을 "좋다"고 볼지의 기준이 들어감).

## 1. 무엇을 진단하나
화제가 된 동네(구 단위로 집계)의 **업종 구성**을 `semas_district` 도구로 받아, 소상공인 관점에서 "기회가 있는지·위험한지"를 판단한다.

## 2. 판단 기준
| 신호 | 해석 |
|---|---|
| 특정 업종 비중이 지나치게 높음(예: 음식업 40% 이상) | 경쟁 과열 가능성 — 신규 진입에 신중해야 함 |
| 업종 다양성이 높음(상위 업종 하나가 20% 미만) | 안정적 상권, 특정 업종 쏠림 위험 낮음 |
| 화제 사건(신규 시설·교통망)과 실제 점포 수 증가가 함께 확인됨 | 상권이 실제로 성장 중 — 기회 신호 |
| 화제는 있는데 점포 수 변화를 확인할 방법이 없음(이 API는 스냅샷만 줌) | "지금 이 순간의 구성"만 보고하고, 증감은 다음 주 비교로 넘긴다(회고 기록에 남겨 다음 회차부터 비교 가능하게) |

## 3. 등급
| 등급 | 뜻 |
|---|---|
| **A** | 화제 사건이 실질적(신규 시설·교통망)이고 업종 구성이 건강함(과열 업종 없음) |
| **B** | 화제는 있으나 업종 구성 자체는 평범(과열도 특별한 강점도 없음) |
| **C** | 특정 업종 과열 신호가 있어 신규 진입 주의 |
| **D** | 임대료·공실 등 부정적 신호가 화제의 중심 |
| **판단 불가** | `semas_district` 도구가 그 구의 자료를 못 줌(구 코드 오류 등) |

## 4. 소상공인에게 실질적으로 전할 조언
- 등급 A: "이 동네·이 시기에 관심 가질 만함"
- 등급 C: "이 업종은 이미 몰려 있어 신규 진입 시 차별화 필요"
- 등급 D: "당분간 지켜볼 필요"

## 5. 숫자 규칙
- 점포 수·비중은 `semas_district` 도구 값 그대로 인용(기간: 도구가 준 최신 스냅샷). 폐업률·개업률 데이터는 이 도구에 없다 — 있는 척하지 않는다.
